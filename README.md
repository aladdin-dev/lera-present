# Сайт учителя физики — Валерия Александровна Хафоева

Статический сайт без сборки: обычные HTML, CSS и JavaScript.
Достаточно открыть `index.html` или выложить папку на GitHub Pages.

## Локальный просмотр

Сайт работает и просто из папки (`index.html`), но браузеры из соображений
безопасности могут не загружать локальные шрифты с `file://` — тогда
заголовки покажутся системным шрифтом. Чтобы увидеть всё как на хостинге,
запустите в папке сайта простой сервер:

```bash
python -m http.server 8000
```

и откройте `http://localhost:8000`.

## Структура
```
index.html              — разметка страницы
favicon.svg             — иконка сайта
assets/
  css/style.css         — все стили и анимации
  js/data.js            — ДАННЫЕ: фотографии, приложения, игры
  js/main.js            — интерактивность (меню, галерея, просмотр фото)
  fonts/                — шрифты Manrope и Unbounded (локально)
  img/                  — фотографии: hero, portrait, обложки, og
  img/gallery/          — фотографии галереи (превью `-sm` и полный размер)
```

## Как добавить приложение в «Методическую копилку»

1. Открыть `assets/js/data.js`.
2. Найти массив `TOOLS` и добавить в него новый блок:

```js
{
  title: 'Название приложения',
  subtitle: 'Короткая подпись',
  description: 'Одно-два предложения: чем полезно приложение.',
  url: 'https://aladdin-dev.github.io/novoe-prilozhenie/',
  tag: 'Тесты',
  icon: 'test'
}
```

3. Сохранить файл — карточка появится на сайте автоматически,
   счётчик и пункт «Раздел пополняется» сдвинутся сами.

Доступные иконки: `calc`, `test`, `book`, `atom`, `robot`, `gamepad`, `ship`.

## Как добавить игру в «Переменку»

То же самое, но в массиве `GAMES`:

```js
{
  title: 'Название игры',
  subtitle: 'Игра на двоих',
  description: 'Пара предложений о правилах.',
  url: 'https://example.com/game/',
  tag: 'На двоих',
  icon: 'gamepad'
}
```

У первой игры стоит `featured: true` — она показывается большой карточкой.
Чтобы выделить другую игру, перенесите `featured: true` в её блок.

## Как добавить фотографию в галерею

1. Положить два файла в `assets/img/gallery/`:
   - `id.webp` — полный размер (до 1500 px по длинной стороне),
   - `id-sm.webp` — превью (до 720 px).
2. Добавить строку в массив `GALLERY`:

```js
{ id: 'e9', cat: 'edu', w: 540, h: 720, title: 'Подпись на фото', alt: 'Описание для незрячих' }
```

`cat` — категория: `ach` (достижения), `edu` (учебный процесс),
`rob` (робототехника), `evt` (события). `w` и `h` — размеры превью в пикселях.

## Публикация на GitHub Pages

Сайт опубликован: **https://aladdin-dev.github.io/lera-present/**  
Репозиторий: `aladdin-dev/lera-present`. GitHub Pages собирает ветку
`gh-pages` (папка `/`), при этом ветки `master` и `gh-pages` содержат
одну и ту же версию сайта.

Обновление сайта — обычный коммит и пуш в обе ветки:

```bash
git add -A
git commit -m "Обновление сайта"
git push origin master
git push origin master:gh-pages
```

Через минуту после пуша изменения появятся на сайте (сборку и статус
можно посмотреть в репозитории: Actions / Settings → Pages).

Адреса `canonical`, `og:url` и `og:image` в `index.html` уже указывают на
`https://aladdin-dev.github.io/lera-present/`. Если репозиторий или аккаунт
сменится — поправьте их в `<head>` и в JSON-LD.
